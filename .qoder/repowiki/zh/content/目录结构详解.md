## 核心模块分析

### 后端服务模块

后端基于Express框架构建，提供用户注册、登录和管理接口，使用SQLite作为持久化存储。

``mermaid
sequenceDiagram
participant 前端 as 前端应用
participant Express as Express服务器
participant SQLite as SQLite数据库
前端->>Express : POST /api/register
Express->>SQLite : 检查用户名/邮箱是否已存在
alt 用户不存在
Express->>SQLite : 插入新用户(密码已加密)
SQLite-->>Express : 返回插入结果
Express-->>前端 : 返回注册成功
else 用户已存在
Express-->>前端 : 返回错误信息
end
前端->>Express : POST /api/login
Express->>SQLite : 查询用户信息
alt 用户存在
Express->>Express : 验证密码
alt 密码正确
Express-->>前端 : 返回登录成功和用户信息
else 密码错误
Express-->>前端 : 返回认证失败
end
else 用户不存在
Express-->>前端 : 返回认证失败
end
```
