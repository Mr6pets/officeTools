## 项目概述

officeTools 是一个集成了多种办公实用功能的桌面应用程序，提供文件压缩、图片处理、文本工具、开发工具、网络工具等多功能服务。项目采用现代化的全栈技术架构，前端使用 React + TypeScript 构建用户界面，通过 Vite 实现快速开发和构建，后端使用 Express.js 提供 API 服务，最终通过 Electron 实现桌面化部署。项目结构清晰，功能模块化，支持主题切换和多语言，旨在为用户提供高效便捷的办公工具集。

## 前端技术栈

### React 与 TypeScript

项目前端采用 React 作为核心 UI 库，结合 TypeScript 提供类型安全。React 的组件化架构使得各个工具功能（如文件压缩、图片OCR、代码格式化等）可以独立开发和维护。TypeScript 的引入显著提升了代码的可维护性和开发体验，通过静态类型检查减少了运行时错误。

在 `tsconfig.json` 配置文件中，项目启用了严格的类型检查选项，包括 `"strict": true`、`"noUnusedLocals": true` 和 `"noUnusedParameters": true`，确保代码质量。

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true
  },
  "include": ["src"]
}
```

### Ant Design UI 框架

项目使用 Ant Design 作为 UI 组件库，通过 `antd` 包提供丰富的预构建组件，如按钮、卡片、上传、进度条等。这大大加速了 UI 开发过程，确保了界面的一致性和专业性。在 `package.json` 中可以看到 `antd` 的版本为 `^5.12.0`。

### 主题切换机制

项目实现了完整的主题切换功能，支持亮色、暗色和自动模式。`useTheme` 自定义 Hook 管理主题状态，根据用户选择、系统偏好和当前时间自动切换主题。

```typescript
// src/hooks/useTheme.ts
export type ThemeMode = 'light' | 'dark' | 'auto';

const applyTheme = (isDark: boolean) => {
  if (isDark) {
    document.documentElement.classList.add('dark');
    document.documentElement.setAttribute('data-theme', 'dark');
  } else {
    document.documentElement.classList.remove('dark');
    document.documentElement.setAttribute('data-theme', 'light');
  }
};
```

## 后端技术栈

### Express.js API 服务

后端采用 Express.js 框架构建 RESTful API 服务，处理用户注册、登录和用户管理等核心功能。服务器文件 `backend/server.js` 中定义了三个主要接口：`/api/register`、`/api/login` 和 `/api/users`。

```javascript
// backend/server.js
const app = express();
app.use(cors());
app.use(express.json());

app.post('/api/register', async (req, res) => { /* 注册逻辑 */ });
app.post('/api/login', async (req, res) => { /* 登录逻辑 */ });
app.get('/api/users', (req, res) => { /* 获取用户列表 */ });
```

### better-sqlite3 数据库

项目使用 better-sqlite3 作为 SQLite 数据库的 Node.js 驱动，提供高性能的数据库操作。数据库文件 `users.db` 存储用户信息，包含 id、username、email、password 和 created_at 字段。

```javascript
// backend/server.js
const Database = require('better-sqlite3');
const db = new Database(DB_FILE);
db.exec(`
  CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT UNIQUE NOT NULL,
    email TEXT UNIQUE NOT NULL,
    password TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
  )
`);
```

### bcrypt 密码加密

用户密码通过 bcrypt 库进行加密存储，确保安全性。在注册时，密码经过 `bcrypt.hash()` 处理后存入数据库；在登录时，使用 `bcrypt.compare()` 验证密码。

```javascript
// backend/server.js
const hashedPassword = await bcrypt.hash(password, 10);
const isValidPassword = await bcrypt.compare(password, user.password);
```

## 构建与打包工具

### Vite 构建系统

项目采用 Vite 作为现代前端构建工具，提供快速的开发服务器和高效的生产构建。Vite 配置文件 `vite.config.ts` 中定义了插件、基础路径、输出目录和开发服务器端口。

```typescript
// vite.config.ts
export default defineConfig({
  plugins: [react()],
  base: './',
  build: {
    outDir: 'dist',
    assetsDir: 'assets'
  },
  server: {
    port: 5173
  }
});
```

在 `package.json` 的 scripts 中，`dev` 脚本启动 Vite 开发服务器，`build` 脚本执行 TypeScript 编译和 Vite 构建。

```json
"scripts": {
  "dev": "vite",
  "build": "tsc && vite build",
  "preview": "vite preview"
}
```

## 桌面化支持

### Electron 桌面应用

项目通过 Electron 实现桌面化，将 Web 应用打包为跨平台的桌面应用程序。`public/electron.js` 是 Electron 的主进程文件，负责创建浏览器窗口、加载应用页面和管理应用生命周期。

```javascript
// public/electron.js
function createWindow() {
  mainWindow = new BrowserWindow({
    width: 1200,
    height: 800,
    webPreferences: {
      nodeIntegration: false,
      contextIsolation: true
    }
  });
  
  const startUrl = isDev ? 'http://localhost:5173' : `file://${path.join(__dirname, '../dist/index.html')}`;
  mainWindow.loadURL(startUrl);
}
```

### 应用菜单与系统集成

Electron 实现了完整的应用菜单，包括文件、编辑、视图和帮助等标准菜单项。菜单支持平台特定的快捷键，如在 macOS 上使用 Cmd+Q 退出，在 Windows/Linux 上使用 Ctrl+Q 退出。

```javascript
const template = [
  {
    label: '文件',
    submenu: [
      {
        label: '退出',
        accelerator: process.platform === 'darwin' ? 'Cmd+Q' : 'Ctrl+Q',
        click: () => app.quit()
      }
    ]
  }
];
```

## 关键依赖库分析

### jszip - 文件压缩

`jszip` 库用于实现文件压缩功能，在 `FileCompressor.tsx` 组件中创建 ZIP 压缩包。

```typescript
// src/components/FileCompressor.tsx
const zip = new JSZip();
files.forEach((fileItem) => {
  zip.file(fileItem.name, fileItem.file);
});
const content = await zip.generateAsync({ type: 'blob' });
```

### pdf-lib - PDF 处理

`pdf-lib` 库用于 PDF 文件的创建和操作，虽然在 `PDFTools.tsx` 中目前是模拟实现，但为未来的 PDF 合并和分割功能提供了基础。

```typescript
// src/components/PDFTools.tsx
const PDFMerger: React.FC = () => {
  // PDF合并逻辑
  setTimeout(() => {
    message.success('PDF合并完成');
  }, 2000);
};
```

### tesseract.js - 图片OCR

`tesseract.js` 是一个 JavaScript OCR 引擎，用于从图片中提取文字。在 `ImageOCR.tsx` 组件中，支持中文、英文等多种语言识别。

```typescript
// src/components/ImageOCR.tsx
const worker = await createWorker(language);
const { data: { text } } = await worker.recognize(imageUrl);
```

### qrcode - 二维码生成

`qrcode` 库用于生成二维码，在 `QRCodeTools.tsx` 组件中将文本内容转换为二维码图像。

```typescript
// src/components/QRCodeTools.tsx
const url = await QRCode.toDataURL(qrText, { width: qrSize });
setQrCodeUrl(url);
```

### prettier - 代码格式化

`prettier` 库用于代码格式化，在 `CodeFormatter.tsx` 组件中支持 JavaScript、TypeScript、HTML、CSS 等多种语言的格式化。

```typescript
// src/components/CodeFormatter.tsx
import prettier from 'prettier/standalone';
import parserBabel from 'prettier/parser-babel';
import parserTypescript from 'prettier/parser-typescript';

const formatted = await prettier.format(inputCode, {
  parser: config.parser,
  plugins: config.plugins,
  ...formatOptions
});
```

### crypto-js - 加密解密

`crypto-js` 库提供多种加密算法支持，在 `CryptoTools.tsx` 组件中实现 AES、DES 加密解密和 MD5、SHA 等哈希计算。

```typescript
// src/components/CryptoTools.tsx
const encrypted = CryptoJS.AES.encrypt(text, key).toString();
const decrypted = CryptoJS.AES.decrypt(encryptedText, key).toString(CryptoJS.enc.Utf8);
const hash = CryptoJS.MD5(input).toString();
```

## 环境要求与版本兼容性

### Node.js 版本要求

项目需要 Node.js 16 或更高版本。从 `package.json` 中的依赖版本可以看出，项目使用了现代 JavaScript 特性，需要较新的 Node.js 版本支持。

### 操作系统支持

由于使用 Electron，项目支持三大主流操作系统：
- **Windows**: 支持 NSIS 安装包
- **macOS**: 支持 DMG 安装包
- **Linux**: 支持 AppImage 格式

在 `package.json` 的 `build` 配置中明确指定了各平台的打包目标。

```json
"build": {
  "mac": {
    "target": "dmg"
  },
  "win": {
    "target": "nsis"
  },
  "linux": {
    "target": "AppImage"
  }
}
```

### 开发环境搭建

1. 克隆项目仓库
2. 运行 `npm install` 安装所有依赖
3. 运行 `npm run dev` 启动开发服务器
4. 运行 `npm run electron-dev` 启动桌面应用开发模式
5. 运行 `npm run electron-pack` 打包生产版本

```json
"scripts": {
  "electron": "concurrently \"npm run dev\" \"wait-on http://localhost:5173 && electron .\"",
  "electron-pack": "npm run build && electron-builder"
}
```
