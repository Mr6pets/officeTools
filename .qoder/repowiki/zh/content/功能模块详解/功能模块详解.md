## 文件处理工具

文件处理工具模块主要提供对文件内容的格式化、转换和压缩功能，适用于需要快速处理结构化数据或批量操作文件的场景。该模块解决了用户在日常办公中频繁遇到的JSON数据可读性差、文件体积过大等问题。

### JSON格式化

JSON格式化工具（`JSONFormatter`）提供JSON数据的格式化、压缩、验证和统计功能。其核心实现基于JavaScript原生的`JSON.parse()`和`JSON.stringify()`方法，无需额外依赖库。

**实现原理**：
1. **格式化**：通过`JSON.stringify(parsed, null, indentSize)`添加缩进，提升可读性
2. **压缩**：通过`JSON.stringify(parsed)`移除所有空白字符，减小文件体积
3. **验证**：使用`JSON.parse()`尝试解析，捕获语法错误
4. **统计**：递归遍历解析后的对象，统计键、值、对象、数组数量及数据大小

**适用场景**：
- 调试API返回的JSON数据
- 减小JSON文件体积以优化传输
- 验证JSON语法正确性
- 分析JSON数据结构复杂度

```
flowchart TD
Start([输入JSON]) --> Validate{语法正确?}
Validate --> |否| ShowError[显示错误信息]
Validate --> |是| Process{选择操作}

Process --> Compress["压缩\n(移除空白)"]

```

### 文件压缩

文件压缩工具（`FileCompressor`）基于`JSZip`库实现，能够将多个文件批量压缩为ZIP格式。该功能解决了文件传输和存储时的体积优化问题。

**技术依赖**：
- `JSZip`：用于创建和生成ZIP压缩包
- `FileSaver.js`：用于触发浏览器下载文件
- 浏览器File API：用于读取用户上传的文件

**实现流程**：
1. 用户上传一个或多个文件
2. 使用JSZip库创建压缩包实例
3. 将每个文件添加到压缩包中
4. 生成Blob格式的压缩包内容
5. 通过FileSaver.js触发下载

**核心代码**：
```typescript
const handleCompress = async () => {
  const zip = new JSZip();
  
  // 添加文件到压缩包
  files.forEach(fileItem => {
    zip.file(fileItem.name, fileItem.file);
  });

  // 生成压缩包
  const content = await zip.generateAsync({
    type: 'blob',
    compression: 'DEFLATE',
    compressionOptions: { level: 6 }
  });

  // 下载文件
  saveAs(content, `compressed_${timestamp}.zip`);
};
```

**适用场景**：
- 批量文件归档
- 减小文件体积以便传输
- 创建项目备份包
- 网站资源打包

### 图片压缩

图片压缩工具（`ImageCompressor`）通过Canvas API实现图片质量调整和格式转换，能够在保持视觉质量的同时显著减小图片文件大小。

**技术依赖**：
- HTML5 Canvas API：用于图片渲染和压缩
- 浏览器File API：用于读取和处理图片文件
- `FileSaver.js`：用于下载压缩后的图片

**实现原理**：
1. 将上传的图片加载到Image对象
2. 创建Canvas元素并绘制图片
3. 使用`canvas.toBlob()`方法以指定质量保存为JPEG格式
4. 计算压缩率并显示结果

**核心特性**：
- 可调节压缩质量（10%-100%）
- 实时显示压缩前后大小对比
- 支持批量处理多张图片
- 显示总体节省空间统计

**适用场景**：
- 网页图片优化
- 社交媒体图片准备
- 邮件附件大小优化
- 移动设备图片传输

## 图像工具

图像工具模块提供图像压缩、编辑和OCR识别功能，帮助用户优化图像资源并提取图像中的文字信息。该模块特别适用于文档数字化、网页性能优化等场景。

**技术依赖**：
- `tesseract.js`：基于WebAssembly的OCR引擎，支持多语言识别
- 浏览器File API：用于读取用户上传的图像文件
- Canvas API：用于图像预处理和显示

**实现流程**：
1. 用户上传图像文件
2. 使用Tesseract.js加载OCR引擎
3. 对图像进行文字识别
4. 返回识别结果并显示

**适用场景**：
- 扫描文档内容提取
- 截图中的文字复制
- 纸质表单数字化
- 图像内容索引

## 文本工具

文本工具模块专注于文本内容的处理与分析，提供文本对比、编码转换等实用功能，适用于代码审查、文档修订、文本分析等场景。

### 文本对比

文本对比工具（`TextDiff`）实现了一个简易的差异算法，支持行级、词级和字符级的文本比较。该工具解决了文档版本对比、代码变更审查等需求。

**实现原理**：
1. **预处理**：根据用户设置忽略大小写或空白字符
2. **分段比较**：
   - 行级：按换行符分割后逐行比较
   - 词级：按空白字符分割后逐词比较  
   - 字符级：逐字符比较
3. **结果渲染**：使用不同颜色和样式标记新增、删除和未变更的内容

**核心算法**：
```typescript
const computeDiff = (text1: string, text2: string): DiffResult[] => {
  // 预处理文本（忽略大小写/空白）
  let processedText1 = ignoreCase ? text1.toLowerCase() : text1;
  processedText1 = ignoreWhitespace ? processedText1.replace(/\s+/g, ' ').trim() : processedText1;
  
  // 根据模式分割文本并比较
  if (diffMode === 'line') {
    const lines1 = processedText1.split('\n');
    const lines2 = processedText2.split('\n');
    // ...逐行比较逻辑
  }
  // ...其他模式
}
```

**适用场景**：
- 文档修订版本对比
- 代码变更审查
- 合同条款变更检测
- 学术论文修改追踪

```
flowchart TD
Input[输入原文本和新文本] --> Preprocess[预处理]

ByLine --> Compare[逐项比较]

```

## 网络工具

网络工具模块提供一系列网络相关的实用功能，包括URL编码、Base64转换、IP查询等，适用于Web开发、网络安全分析等场景。

### 网络工具集

网络工具（`NetworkTools`）整合了多种常用的网络处理功能，通过标签页组织不同工具。

**包含的功能**：
1. **URL编码/解码**：使用`encodeURIComponent()`和`decodeURIComponent()`
2. **Base64编码/解码**：使用`btoa()`和`atob()`结合`escape()`和`unescape()`
3. **IP查询**：通过API查询IP地理位置信息（当前为模拟数据）
4. **端口检测**：模拟端口扫描，显示常见端口对应的服务
5. **Hash计算**：使用Web Crypto API计算SHA-1、SHA-256等哈希值

**技术实现**：
- **URL编码**：直接使用JavaScript内置函数
- **Base64**：处理Unicode字符的兼容性编码
- **Hash计算**：使用`crypto.subtle.digest()` API
- **端口检测**：当前为模拟实现，返回随机结果

**适用场景**：
- URL参数处理
- 数据编码传输
- 网络安全分析
- 系统管理
