## 简介
本指南旨在为新贡献者提供全面的开发指导，涵盖从环境搭建到功能开发的完整流程。`officeTools` 是一个多功能办公工具集，采用前后端分离架构，前端使用 React + TypeScript + Vite 技术栈，后端使用 Node.js + Express 构建。项目包含文件处理、图片工具、文本工具、开发工具等多种实用功能。

## 开发环境搭建
### 克隆仓库
```bash
git clone https://github.com/Mr6pets/officeTools.git
cd officeTools
```

### 安装依赖
项目包含前端和后端两个部分，需要分别安装依赖。

```bash
# 安装前端依赖
npm install

# 安装后端依赖
cd backend
npm install
cd ..
```

### 启动开发服务器
#### 前端开发服务器
```bash
npm run dev
```
此命令使用 Vite 启动前端开发服务器，默认监听 `http://localhost:5173`。

#### 后端开发服务器
```bash
# 在 backend 目录下
npm start
```
或使用直接命令：
```bash
node server.js
```
后端服务器默认监听 `http://localhost:3088`。

#### 同时启动前后端
项目提供了便捷的脚本同时启动前后端服务：
```bash
npm run electron-dev
```
该命令使用 `concurrently` 工具并行运行前端开发服务器和 Electron 应用。

## 代码风格与规范
### TypeScript 配置
项目使用 TypeScript 作为主要开发语言，配置文件 `tsconfig.json` 定义了严格的类型检查规则：

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noFallthroughCasesInSwitch": true
  },
  "include": ["src"]
}
```

关键配置说明：
- **严格模式**：启用所有严格类型检查选项
- **无未使用变量**：禁止声明但未使用的局部变量和参数
- **无遗漏的 switch case**：要求 switch 语句包含所有可能的情况

### React Hooks 使用规范
项目采用函数式组件和 React Hooks 进行状态管理，遵循以下最佳实践：

1. **useState 使用**：为状态变量提供明确的类型注解
```typescript
const [selectedKey, setSelectedKey] = useState<MenuKey>('compress');
const [text, setText] = useState('');
```

2. **自定义 Hook**：项目已实现 `useTheme` Hook 用于主题管理
```typescript
import { useTheme } from './hooks/useTheme';
const { theme } = useTheme();
```

3. **状态更新**：使用函数式更新确保状态一致性
```typescript
setCount(prev => prev + 1);
```

### 主题与样式规范
#### CSS 变量使用
项目在 `src/index.css` 中定义了一套完整的CSS变量系统，用于实现主题一致性：

```css
:root {
  /* 颜色变量 */
  --primary-color: #8b8fb8;
  --text-primary: #1e293b;
  --bg-primary: #ffffff;
  
  /* 阴影变量 */
  --shadow-md: 0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1);
  
  /* 圆角变量 */
  --radius-lg: 12px;
  
  /* 间距变量 */
  --spacing-md: 16px;
}
```

所有组件应优先使用这些CSS变量而非硬编码值，确保主题切换时样式一致性。

#### 暗黑模式实现
项目通过以下机制实现暗黑模式：

1. **CSS 类切换**：在 `:root` 元素上添加 `dark` 类或设置 `data-theme="dark"` 属性
2. **CSS 变量重定义**：在暗黑模式下重定义所有颜色变量
```css
:root.dark, [data-theme="dark"] {
  --primary-color: #9ca3c4;
  --text-primary: #f1f5f9;
  --bg-primary: #1a202c;
}
```

3. **JavaScript 控制**：通过 `useTheme` Hook 动态控制主题状态

4. **自动模式**：支持根据系统偏好和时间（18:00-6:00）自动切换主题

#### Ant Design Tabs 组件使用规范
根据最新代码变更，项目中所有使用 Ant Design Tabs 组件的地方均已更新为使用 `items` 属性配置标签页，替代了旧的 `TabPane` 写法。这是推荐的现代化配置方式。

```tsx
const tabItems = [
  {
    key: 'password',
    label: '密码生成',
    children: <PasswordGenerator />
  },
  {
    key: 'uuid',
    label: 'UUID生成',
    children: <UUIDGenerator />
  }
];

return (
  <Tabs defaultActiveKey="password" items={tabItems} />
);
```

这种写法更加简洁，便于动态生成标签页，且与 Ant Design 最佳实践保持一致。

## 提交信息与分支管理
### 提交信息格式
项目未明确指定提交信息格式规范，建议采用常规的约定式提交（Conventional Commits）格式：

```
<type>(<scope>): <subject>
<BLANK LINE>
<body>
<BLANK LINE>
<footer>
```

常用类型包括：
- `feat`：新增功能
- `fix`：bug 修复
- `docs`：文档更新
- `style`：代码格式调整
- `refactor`：代码重构
- `test`：测试相关
- `chore`：构建过程或辅助工具的变动

### 分支管理策略
项目未在代码库中明确说明分支管理策略，建议采用以下通用策略：

1. **主分支**：
   - `main`：生产环境代码，受保护
   - `develop`：开发集成分支

2. **功能分支**：
   - 命名格式：`feature/<功能名称>`
   - 从 `develop` 分支创建
   - 完成后合并回 `develop`

3. **修复分支**：
   - 命名格式：`hotfix/<问题描述>`
   - 从 `main` 分支创建
   - 修复后同时合并到 `main` 和 `develop`

## 添加新工具
### 完整开发流程示例：扩展新的文本处理工具
以下以在 "文本工具" 分类下添加 "文本反转" 工具为例，演示完整开发流程。

#### 步骤1：创建新组件
在 `src/components` 目录下创建 `TextReverser.tsx` 文件：

```tsx
import React, { useState } from 'react';
import { Card, Input, Button, Space, message } from 'antd';
import { CopyOutlined } from '@ant-design/icons';

const { TextArea } = Input;

const TextReverser: React.FC = () => {
  const [inputText, setInputText] = useState('');
  const [outputText, setOutputText] = useState('');

  // 反转文本
  const reverseText = () => {
    const reversed = inputText.split('').reverse().join('');
    setOutputText(reversed);
  };

  // 复制结果
  const copyResult = () => {
    navigator.clipboard.writeText(outputText);
    message.success('已复制到剪贴板');
  };

  return (
    <Card title="文本反转">
      <Space direction="vertical" style={{ width: '100%' }}>
        <TextArea
          value={inputText}
          onChange={(e) => setInputText(e.target.value)}
          placeholder="请输入要反转的文本"
          rows={6}
        />
        
        <Button type="primary" onClick={reverseText}>
          反转文本
        </Button>
        
        <TextArea
          value={outputText}
          placeholder="反转结果"
          rows={6}
          readOnly
        />
        
        <Button 
          icon={<CopyOutlined />} 
          onClick={copyResult}
          disabled={!outputText}
        >
          复制结果
        </Button>
      </Space>
    </Card>
  );
};

export default TextReverser;
```

#### 步骤2：在工具注册表中注册
编辑 `src/utils/toolRegistry.ts` 文件，在 "文本工具" 分类中添加新工具：

## 调试与测试
### 调试技巧
#### 前端调试
1. **浏览器开发者工具**：使用 Chrome DevTools 检查组件状态、网络请求和控制台日志
2. **React DevTools**：安装 React 开发者工具扩展，检查组件树和 props 状态
3. **TypeScript 错误**：关注编辑器中的类型错误提示，确保类型安全

#### 后端调试
1. **控制台日志**：后端服务器启动时会输出日志
```bash
服务器运行在 http://localhost:3088
数据库文件: backend/users.db
数据库初始化完成
```

2. **API 测试**：使用 curl 或 Postman 测试后端 API
```bash
# 测试用户注册
curl -X POST http://localhost:3088/api/register \
  -H "Content-Type: application/json" \
  -d '{"username":"test","email":"test@example.com","password":"123456"}'
```

#### 主题调试
1. **CSS 变量检查**：在开发者工具中检查 `:root` 元素的CSS变量值
2. **主题类验证**：确认 `html` 元素是否正确添加了 `dark` 类
3. **本地存储检查**：查看 `localStorage` 中的 `office-tools-theme` 项
4. **时间模拟**：在控制台执行 `new Date().setHours(20)` 测试自动夜间模式

### 日志查看
#### 前端日志
- Vite 开发服务器日志：直接在终端查看
- 浏览器控制台日志：使用 `F12` 打开开发者工具

### 本地测试方法
#### 单元测试
项目未包含测试框架，建议添加 Jest 和 React Testing Library 进行单元测试。

#### 手动测试流程
1. **功能测试**：验证新工具的基本功能是否正常

2. 在真实环境中测试工具的完整工作流
